# Claude Code Haha v0.7.1

这是一次小版本更新:聊天输入框的换行快捷键现在可以自己选了。设置里的「消息发送方式」之下新增「消息换行快捷键」,默认 Ctrl+Enter,可切换 Alt+Enter、Shift+Enter 或 Enter,并且不会和发送快捷键重复。

## 核心功能

- **消息换行快捷键可配置**:设置 → 通用 → Agent 偏好中,「消息发送方式」新增「消息换行快捷键」设置。默认 Ctrl+Enter 换行,可选 Alt+Enter、Shift+Enter 或 Enter。换行快捷键与发送快捷键是同一个组合时无法同时成立,设置页会把冲突的选项置灰;切换发送方式导致冲突时,换行快捷键自动迁移到该发送方式下的默认值,并同一次写入保存。
- **快捷键真实生效**:对话输入框、新会话输入框和编辑已发送消息的编辑器都按设置的快捷键执行发送与换行;未配置的 Enter 组合不再隐式插入换行。远程浏览器(H5/公开访问)的设置读写白名单同步开放该字段并校验取值。

# Claude Code Haha v0.7.1

A minor release: the chat composer's line break shortcut is now configurable. Settings gains a "Message Line Break" option under the message send behavior — Ctrl+Enter by default, switchable to Alt+Enter, Shift+Enter or Enter, and it can never duplicate the send shortcut.

## Highlights

- **Configurable line break shortcut**: under Settings → General → Agent preferences, the message send behavior row is joined by a message line break row. Ctrl+Enter is the default, with Alt+Enter, Shift+Enter and Enter as options. A line break combo that duplicates the send shortcut cannot be selected — the conflicting option is disabled in the UI, and switching the send behavior to a conflicting combo migrates the line break shortcut to that send mode's default in the same save.
- **The shortcuts take effect everywhere**: the chat composer, the new-session composer and the edit-and-resend editor all submit and insert line breaks per the configured shortcuts, and unconfigured Enter combos no longer insert a line break implicitly. The remote browser (H5/public access) settings read/write allowlist opens the same field with value validation.
